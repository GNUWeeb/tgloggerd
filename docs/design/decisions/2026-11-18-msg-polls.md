# Decision log: 2026-11-18, Polls in their own tables, latest results only

Decided by the TDLib session on 2026-11-18 and approved by the
project owner the same day, for
[../message-types.md](../message-types.md) section 4.4:

- Polls are stored in `telegram_polls` and `telegram_poll_options`,
  keyed by TDLib's poll id; the message points at the poll from
  `content_extra`.
- `updatePoll` overwrites the results (voter counts, closed state) in
  place; results are not versioned and do not create edit snapshots.
- Individual votes are not stored.
- Reason: a poll's results change with every vote and arrive keyed by
  poll, not by message, so keeping them on the message row would make
  every vote an edit, which `is_server_churn_content` already avoids.
  A user account sees only its own vote; others' votes reach bots only.
