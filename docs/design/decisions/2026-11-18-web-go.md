# Decision log: 2026-11-18, Web backend in Go

Decided with the project owner on 2026-11-18, for
[../web-go.md](../web-go.md):

- The web backend moves from Drogon (C++) to Go, gradually: a Go
  service serves the new JSON API beside the Drogon web, features move
  one by one, and Drogon is retired when nothing routes to it.
- The daemons (tgloggerd, discordd) stay C++.
- The Go module path names no repository host (`tgloggerd/webapi`), so
  the code is not tied to any hosting account. Third-party modules are
  few, keep their upstream paths and are vendored in the repository,
  so builds never fetch from the network.
- The accounts and federations work is built in Go, not in Drogon.
