# Decision log: 2026-11-18, Server rendering of web pages

Decided with the project owner on 2026-11-18, for
[../web-go.md](../web-go.md) section 4:

- Every page is server-rendered: the Go service loads the page's data
  and checks access, and a stateless Node render service (React)
  returns the HTML, with the data embedded for React to take over.
- One render path for all pages, signed in or public; when the render
  service is unavailable, Go serves the application shell with the same
  data, rendered in the browser.
- Node is added to the stack only as that render service, with no
  database access, cookies or secrets.
