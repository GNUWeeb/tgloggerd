# Decision log: 2026-11-18, Every web feature has an API

Decided with the project owner on 2026-11-18, for
[../web-go.md](../web-go.md) section 6:

- Every web feature that reads from or acts on the backend is an
  operation of the JSON API, so that other clients, such as Android
  and iOS applications, can reuse the backend as the dashboard does.
- No feature exists only as a server-rendered page or an HTML form
  post.
