Before you confirm:

  • Settings Telegram does not let the daemon read are not restored, such as a custom photo set for this contact.
  • Telegram limits how often contacts can change, so the daemon runs one lookup at a time with a pause in between and does not retry a refused one.
  • If the daemon stops halfway, it adds the contact back when it starts again.
